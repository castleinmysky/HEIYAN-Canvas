# 源码说明

[返回首页](../README.md) · [快速开始](QUICKSTART.md) · [项目仓库](https://github.com/castleinmysky/HEIYAN-Canvas)

黑岩画布是独立的节点创作空间。你可以在自己的环境部署，连接自己的模型和 Codex，再按自己的需求扩展。

## 仓库内容

| 范围 | 内容 |
| --- | --- |
| 画布 | 节点、连线、引用、成组、历史、昼夜主题与设备适配。 |
| 模型连接 | 分类、API 高级配置、现有图片、视频、音频和 3D 适配。 |
| Codex Agent | 个人连接器、会话界面、用户确认的画布操作。 |
| ComfyUI | 连接器、现有工作流适配、本机及受保护的跨网络接入。 |
| 开发与部署 | 独立 HTTP 服务、配置示例、启动和打包脚本、测试。 |

不包含主平台业务系统、账号权限、消费账单、私人任务、生成结果、API 密钥、Codex 登录态、配对码或 ComfyUI 权重。

演示图片和 GIF 用于展示软件操作，不自动成为可自由使用的生产素材。依赖和媒体的边界见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 参与方式

通过仓库 Issues 反馈问题，通过 Pull Request 提交修改。写清使用版本、系统与浏览器、复现步骤、预期和实际结果即可。

新模型或较大的交互调整，请同时说明使用方式和测试情况。提交前运行检查与测试，见 [贡献说明](../CONTRIBUTING.md)。不要提交真实账号、浏览器数据、登录态或私人作品。
