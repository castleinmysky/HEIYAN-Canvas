# 快速开始

[返回首页](../README.md) · [部署配置](DEPLOYMENT.md) · [源码说明](OPEN-SOURCE.md)

在线画布、Codex 连接器、ComfyUI 是三个不同入口，按需要使用，不必全部安装。

## 部署整套画布

安装 Node.js 22.13 或更新版本，以及 Git。在终端运行：

```bash
git clone https://github.com/castleinmysky/HEIYAN-Canvas.git
cd HEIYAN-Canvas
npm ci
npm run build
npm start
```

打开 [本机画布](http://127.0.0.1:8792)。关闭服务使用终端的 Ctrl+C，不会关闭其他程序。仓库为私有时，克隆和下载需要仓库访问权限。

开发时使用 `npm run dev`，地址相同。端口冲突时配置 `.env`，不要关闭不认识的程序。服务器部署、HTTPS 和升级步骤见 [部署配置](DEPLOYMENT.md)。

## 直接使用在线画布

在线试用站使用 ChatGPT Sites 托管，不是作者自建的独立服务器。部分地区或网络环境需要自备代理工具（梯子），请先确保能访问该托管服务。

试用站不提供模型账号或生成额度，仍需接入自己的 API 或 Codex。若不想依赖试用站，可以按上面的步骤自行部署；访问模型 API 和 Codex 的网络条件仍由相应服务决定。

1. 打开 [在线画布](https://heiyan.f2vfhjcckr.chatgpt.site/)。
2. 新建节点或导入自己的素材。
3. 需要生成时接入服务，再选择模型、规格并提交。

在线版和独立版都以当前浏览器为数据边界。换设备、换浏览器、换访问地址或清除网站数据，不会自动带走画布；重要内容先导出。

## 接入自己的模型 API

在「设置 → API 与模型」按生成类型找到模型，填写自己的密钥。需要其他模型版本、中转站或兼容接口时，打开「高级」：

| 配置 | 填写内容 |
| --- | --- |
| API 密钥 | 你的服务商签发的密钥，不是 Codex 配对码。 |
| 模型 ID | 服务商实际支持的 ID，不是显示名称。 |
| 协议、地址、路径 | 对照服务商文档填写；官方和中转站可能不同。 |
| 规格 | 回到节点设置，以所选模型的真实能力为准。 |

Seedance 等视频服务同样使用用户自己的 API 权限，不包含作者账号或代付额度。部分供应商要求额外开通模型、审核权限，或使用其控制台创建的接入点 ID。

云请求可能经过你部署的画布服务再到供应商。只在信任的部署上填写密钥。连接成功不等于模型、额度和全部规格均已开通。

## 连接自己的 Codex

### Windows 免安装包

1. 从 [Releases](https://github.com/castleinmysky/HEIYAN-Canvas/releases/latest) 下载 `HEIYAN-Connector-Windows-x64.zip`。
2. 完整解压。需要连接其他地址时，将包内 `connector.json` 的 `siteUrl` 改为你实际使用的画布地址；可包含当前任务的完整路径和参数。
3. 双击「启动黑岩连接器.cmd」，按引导登录自己的 Codex。
4. 点击「打开画布并配对」，确认是自己刚启动的连接器，再在画布点击「配对并连接」。

默认连接 `http://127.0.0.1:8792`。连接在线版时先修改 `siteUrl`，停止并重新启动连接器。完整说明见 [Windows 连接器](codex-connector-windows.md)。

网页优先下载部署者提供的本地安装包；没有本地包时，使用按钮下方的 GitHub Releases 下载入口。私有仓库的下载需要先登录有权限的 GitHub 账号。

### 手动启动

准备已安装并登录的 Codex CLI，回到仓库目录运行：

```bash
npm run agent:connector -- --origin http://127.0.0.1:8792
```

把终端显示的地址和配对码填入 Agent。不要把配对码发给其他人。见 [手动连接说明](codex-connector.md)。

Agent 使用自己的 Codex 额度。当前主要读取节点信息、讨论创作和提出可确认的节点操作；不自动提交付费生成，也不承诺自动完成整部短片。目前支持桌面浏览器与同机连接器，手机跨设备连接未开放。

## 接入自己的 ComfyUI

准备好你自己的 ComfyUI、模型及自定义节点，启动 ComfyUI 后，在仓库目录的另一个终端运行：

```bash
npm run comfy:connector -- --origin http://127.0.0.1:8792 --comfy-port 8188
```

打开 [ComfyUI 配对页](http://127.0.0.1:8289/)，复制配对码，在画布「设置 → 远程 ComfyUI 生成 → 当前电脑」中连接。

模型和 LoRA 仍在画布节点中选择。连接器只展示能够发现并由现有适配器支持的能力，不会把任意工作流自动变成通用节点。

跨网络访问、额外模型目录和输出位置见 [ComfyUI 连接器](../local-bridge/README.md)。本仓库不附带作者的完整模型包。

## 保存与恢复

- 画布、模型设置和生成历史主要保存在当前浏览器；没有账号云同步。
- 删除浏览器中的结果，不会删除 ComfyUI 部署机器的原图。
- 同步云请求刷新后不保证恢复；不确定是否提交成功时，不会自动重发扣费。
- 已提交的本地任务需要 ComfyUI 和连接器继续运行。关闭电脑或连接器不保证恢复。
