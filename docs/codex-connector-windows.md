# 黑岩连接器 · Windows

这份 ZIP 包含连接器、Node.js 和 Codex CLI 运行时，不需要另装 Node，也不是自定义 EXE 安装程序。

## 启动

1. 完整解压 `HEIYAN-Connector-Windows-x64.zip` 到自己的文件夹，不要直接在 ZIP 内运行。
2. 默认连接画布 `http://127.0.0.1:8792`。连接其他部署时，先编辑 `connector.json` 中的 `siteUrl`：
   - 可以填写画布首页地址。
   - 也可以填写当前任务画布的完整地址，配对时会保留任务参数。
   - 不要在地址中放密码、API 密钥或其他人的配对码。
3. 双击「启动黑岩连接器.cmd」。
4. 在本机引导页按步骤登录自己的 Codex，点击「打开画布并配对」。
5. 在画布内确认连接器来自自己这台电脑，再点击「配对并连接」。

`connector.json` 中 `port` 为连接端口，默认 17372。修改配置后先停止再启动。

## 停止与安全

关闭引导网页不会停止连接器。需要结束时，在引导页点击「停止连接器」，或双击「停止黑岩连接器.cmd」。

重复启动会复用本包的进程，不会任意结束其他软件。首次配对前请核对打开的是自己的画布，不要把引导页、配对码或状态文件发给他人。

登录由 Codex 负责。[官方认证说明](https://learn.chatgpt.com/docs/auth)。本包不含作者或其他用户的登录信息。读取画布、会话使用自己的 Codex 额度；节点修改按画布审批模式执行。Agent 可集中请求最多 4 个已存在的生成节点，但真实生成不会被自动批准。

当前仅支持 Windows x64 和同机桌面浏览器。手机调用其他电脑的 Codex、关闭连接器后的会话恢复尚未提供。

## 包内容

| 内容 | 用途 |
| --- | --- |
| 启动 / 停止黑岩连接器.cmd | 一键启动与停止。 |
| connector.json | 画布地址与连接端口。 |
| scripts/、server/ | 可查看的连接器源码。 |
| runtime/ | 经 SHA-256 核对的官方 Node.js、Codex CLI 与许可证。 |
| runtime-manifest.json | 运行时来源、版本、文件校验。 |
| LICENSE | 连接器源码许可证。 |

运行状态保存在当前用户的本地应用数据目录。不要将已使用机器的状态、日志或 Codex 登录目录重新打包分享。
