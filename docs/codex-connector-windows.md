# 黑岩 Agent 连接器 · Windows 免安装版

适用于 Windows 10/11 x64。无需安装 Node.js 或输入命令；不是画布网站、ComfyUI 或模型安装包。

## 开始使用

1. 将 ZIP **完整解压**到自己的文件夹，不要在压缩软件里直接运行。
2. 双击 **启动黑岩连接器.cmd**。首次会检查运行文件与稳定版更新，稍等后浏览器打开本机引导页。
3. 若尚未登录，点击“在官方页面登录”，在 OpenAI 官方页面登录自己的账号。密码和 Codex 登录资料不交给画布。
4. 点击“打开画布并配对”。页面会自动填写本机地址与十分钟有效的一次性配对码；检查后点击“配对并连接”。浏览器若询问本地网络访问，请自行决定是否允许。
5. 之后再次双击启动脚本即可。已有本包进程时只打开引导，不会重复启动。连接器关闭、浏览器标签关闭后可能需要重新配对，但不会自动提交消息或消耗额度。

从 1.3.0 起，启动器会通过站点 HTTPS 下载小体积连接器更新，逐文件核对大小与 SHA-256 后才启用。断网、超时或校验失败时会继续使用电脑中已验证的版本；不会覆盖 runtime、connector.json、登录资料或本地状态。只有 Node.js / Codex 固定运行时升级，或启动器自身安全升级时，才需要重新下载完整包。

需要退出时，双击 **停止黑岩连接器.cmd**，或在引导页点击停止。只停止本包启动的连接器、登录进程及其 Codex 子进程，不结束其他 Codex 任务。当前 Agent 会话会结束；原画布和已确认的节点保留。

## 环境与数据

- 包内 runtime 包含固定版本 Node.js 22.23.2、Codex CLI 0.153.4 及配套组件；来源与 SHA-256 见 runtime-manifest.json。没有账号、密钥或模型。连接器应用版本保存在 app/releases，当前选择记录在 app/current.json。
- 不要求管理员权限、不修改系统 PATH、不安装系统服务、不设置开机自启。Windows 安全软件仍可能检查下载脚本；不要通过关闭防护解决警告，应确认下载来源。
- 登录由官方 Codex 管理，复用用户正常的 Codex 登录，不复制作者或用户的认证文件。不会把登录资料放入这个压缩包。
- 本地状态与诊断日志在 `%LOCALAPPDATA%\HEIYAN\AgentConnector`，按解压目录隔离。不要把此目录作为分享包上传。
- 默认仅授权 `https://heiyan.f2vfhjcckr.chatgpt.site`。高级用户可编辑包内 connector.json 的 siteUrl 后重新启动，例如 `http://127.0.0.1:8792`。只接受 HTTPS 或本机 HTTP；不开放局域网或公网。
- 默认端口被其他程序占用时，由系统分配一个空闲端口；配对按钮会自动带上地址，不会抢占或关闭原程序。

## 当前能力与边界

支持使用自己的 Codex 会话、读取带输入/输出端口的画布节点元数据、提出创建/修改/自动匹配端口的连接方案，以及在画布明确确认后一次提交最多 4 个已存在的生成节点。可从当前账号实际可用的 Codex 模型与思考程度中选择；支持在会话输入框直接粘贴最多 4 张 PNG/JPEG/WebP 图片，让支持视觉的所选模型分析后再操作画布。真实生成不会被自动批准。本版不会读取未明确附加的画布图片像素、不听音频、不自动剪辑短片，也不支持手机连接另一台电脑的 Codex。

粘贴图片会在点击发送后交给用户自己的 Codex/OpenAI 处理；连接器只在本轮内转发，不把图片写入连接器日志或更新包。若还要把图片长期留在画布，请另用画布的“导入素材”。

关闭或重启连接器会结束内存中的会话。断网、账号过期或登录被组织限制时，引导会提示问题，不会冒充已连接。发送消息前必须明确在画布完成配对。

## 常见问题

- 启动失败：确认已完整解压、路径可写，查看 `%LOCALAPPDATA%\HEIYAN\AgentConnector` 内对应目录的 startup.log。
- 更新失败：通常无需处理，启动器会使用已验证的旧版本。若提示“更新需要新的完整运行包”，再从画布下载最新版 ZIP。
- 登录未完成：检查网络，返回引导点击登录。不要把密码或认证文件发给他人。
- 已有画布连接：回到原标签页继续；要换标签页，先在原画布断开。不会为了重配对偷偷取消原任务。
- 停止后重新开始：重新双击启动，按引导重新配对。脚本不会强制杀掉来源不明的 PID。
