# 连接你自己的 Codex（源码包）

当前源码包为 **1.6.1**，已与 Windows 包一起重新发布。[下载与更新说明](releases-1.2.1.md)。

普通 Windows x64 用户请优先使用画布连接面板中的“下载 Windows 免安装包”：完整解压后双击“启动黑岩连接器.cmd”，按本机页面引导登录和配对，无需安装 Node.js。此文档对应“其他系统 / 手动启动”中的源码包。

先在本机安装 Node.js 22 或更高版本，以及 Codex CLI，并自行登录 Codex。画布不提供账号、不复制登录凭据、不代售模型额度。

1. 解压连接器压缩包，在解压目录打开终端。
2. 在画布中打开 Agent → Codex 未连接，复制该页面显示的启动命令并运行，例如：

   `npm run agent:connector -- --origin https://heiyan.f2vfhjcckr.chatgpt.site`

   本地正式画布使用 `--origin http://127.0.0.1:8792`。协议、主机和端口必须与浏览器地址一致。
3. 将终端显示的连接地址、十分钟有效的配对码填入画布，点击“配对并连接”。在线页面可能要求允许本地网络访问。
4. 连接成功后才发送消息。消息使用你自己的 Codex 额度；修改节点需按当前审批模式执行，真实媒体生成永远需要在画布明确确认。

连接器仅监听本机回环地址，只允许一个指定网页来源和明确配对的浏览器。关闭终端会断开会话，但不会关闭其他 Codex 任务。新连接不会自动提交消息。

支持会话、读取带端口和 `@` 引用标记的画布节点元数据、编辑与连接节点，以及一次请求最多 4 个已存在的生成节点。1.6.0 连接器可返回当前账号实际可用的模型、思考程度与视觉输入能力；会话框可粘贴最多 4 张 PNG/JPEG/WebP 图片，并显示发送缩略图。明确附加的图片会发送给自己的 Codex/OpenAI。默认读取素材和生成前请求确认；「帮我批准」不自动通过付费生成；主动开启「完全访问权限」后，当前画布可自动读取素材、编辑和付费生成。Agent 不听音频，也不会自动剪辑或生成完整短片。

手机连接另一台电脑的 Codex、跨机远程配对、原生执行线程的持久恢复尚未开放；重新配对可载入网页保存的项目记忆。在线 Site 配对的也是浏览器所在电脑的 Codex，不是网站作者的机器。

若系统找不到 codex，可在本机进程环境中设置 HEIYAN_CODEX_BIN 为自己的 Codex 可执行文件路径；不要向网页或他人发送密码、登录文件和 API 密钥。


## 1.4.0 — 项目上下文与 API 连接

自部署版本按画布在当前浏览器的 IndexedDB 中保存项目要求、目标、进度、摘要、对话原文和执行回执，不需要账号或云存储。连接器依然只使用本机 Codex，不保存 Codex 登录凭据。重新配对时载入已保存的项目上下文，旧操作不自动重放。换浏览器、设备或访问地址不会自动同步这些记录。在线试用站的存储方式独立，不作为自部署的依赖。

在 Agent 的“官方 / 自定义 API”入口填写地址、模型与密钥。官方使用 Responses，自定义支持 Responses 或 Chat Completions。密钥只保留在当前页面内存，通过站点现有 HTTPS 转发接口发送到用户选择的服务，不写入项目记录。测试按钮会发起一次小型模型请求，检查工具调用；图片支持需按模型实际能力启用。API 会话在页面内推进，关闭页面会停止本轮，重新打开可依据记录继续，不承诺后台执行。

默认画布读取返回相关节点与分页概览；节点全文按 16000 字符分页，历史原文按 4500 字符分页。参考图使用单独工具并经用户确认发送。摘要与进度检查点自动保存，修改明确要求或目标仍需确认。API 长工具循环达到设定文本阈值时整理摘要，原文仍保留可检索。该字符阈值不是 token 窗口，也不包含图片 token 的精确估算。

每次生成或修改先持久保存领取记录。提交后但回执未保存的任务显示为结果待核实，不能自动重放。历史聊天中的成功措辞不能替代当前节点和任务状态。

浏览器存储不可用或存在其他页面的写入冲突时，明确提示并阻止没有持久回执保护的新操作，不静默覆盖项目记录。自部署 API 请求走同源 Node 服务，流式响应不经过浏览器画布存储层。


## 1.5.0 — 上下文、检索与任务控制

- API 连接逐项检测工具往返、严格参数、流式响应、可选图片样例、输入 token 计数和原生压缩的继续执行。辅助模型与向量模型仅在用户填写后检测。未通过的可选能力会明确显示并采用受限模式，不改模型或提供方。
- 上下文上限由用户按模型说明填写。支持计数接口时使用服务端计数，否则使用带图片预算的保守估算，并预留输出和安全余量。固定保留当前任务、明确要求、目标与待办；超出最小预算时停止，不静默删去要求。原生压缩保留整个返回窗口；不支持时使用可回查的摘要。
- 关键词检索覆盖对话与当前画布节点；配置 embeddings API 并建立索引后，可组合语义相似度、关键词和节点引用。索引仅在当前页面缓存，最多 6000 段，显示完整覆盖率；内容更改或删除后旧向量不参与匹配。检索结果可以定位节点或原始消息。
- API 逐步显示回复，但只有完整的终止事件到达后才执行工具。只读工具可以并行，画布修改与生成仍顺序确认。主模型负责判断与执行，指定的辅助模型只整理文字摘要。
- 每轮模型调用次数与累计 token 预算可配置。用量优先记录服务商返回的数据；缺少数据时标记估算。可输入每百万 token 单价估算 USD，不代表账单；素材生成、索引与查询另计。
- API 会保留本页同一连接的连续请求历史以便复用上下文缓存；预算整理、重连或切换模型后可能重新计算。缓存 token 以服务端回报为准。
- 连接器协议 5 新增 turn/steer 与 tokenUsage 事件。补充要求只进入当前任务，不建立第二个并发任务；已领取的生成不能被当成未执行操作撤销。旧版协议 4 仍可使用基础功能，新能力需要更新至 1.5.0。
- 用户可在图片确认时仅为本轮指定节点授予再次读取权限。任务结束或停止后失效，不扩展到其他节点、删除、覆盖内容或素材生成。

验证范围：模拟服务覆盖流式断开、补充要求、预算停止、原生压缩回放、语义索引失效和连接器请求身份。真实 API、Windows 实机及浏览器交互仍需使用实际配置验证。


## 1.6.0 — 画布交互与生成结果

- 修改方案使用同一个预检计划生成预览并提交；节点缩略图、名称、描述、参数、位置与输入变化可以逐项查看。预览不会修改画布。定位节点与进度更新不会使内容审批无故失效，提示词、素材、任务身份与结构变化仍要求重新核对。
- 编辑完成和素材返回时高亮对应节点，并可自动定位；可关闭跟随。会话执行卡可定位节点，选中节点后可回查相关记录。完整画布撤销沿用现有功能，本版不提供按整次 Agent 会话回退。
- 元数据新增位置、实际尺寸、父子与收纳关系、可见区域。layout 可排列行、列、网格、对齐或放到参考节点右侧/下方；根据尺寸计算位置，跨父节点转换坐标，可能重叠时提示。
- 生成回执保留具体 jobId 与当时请求的数量、规格。按该任务读取实际状态及历史输出，不使用节点上残留的旧素材冒充新结果；没有可核实信息时显示未知。结果卡显示实际进度、各个素材、预览/播放与下载，并检查可核实的数量、尺寸、比例和视频时长。缺少数据或模型定义的规格标为未核实。
- 协议 6 新增 heiyan_read_generation（每次最多等待 60 秒）与 heiyan_review_result。API 执行器提交成功后自动观察结果，等待本身不调用模型；超过 15 分钟后由下一轮模型判断继续等待，停止或补充要求可中断等待。Codex 使用同一任务读取工具按步骤等待。页面关闭后不承诺继续执行或评估，重开可按已保存的任务编号核实。
- 读取生成图片可指定 jobIds/outputIndexes，确认卡显示对应版本和结果序号；仅在实际读取成功后记录本轮证据。较大的检查图按传输上限缩小，原图不变。只有本次全部图片已经读取、可核实参数均通过时，才能记录 meets；其他结果可记录需调整或未核实。该结论是 Agent 评估，不等同人工验收。
- 视频、声音与3D完整内容不因返回文件或缩略图而判为通过。修正和重试会先说明原因，并重新经过画布修改与付费生成确认。记录结果评估不会调用生成服务。

验证覆盖：空间坐标、分组限制、预览与执行一致性相关逻辑、旧结果归属、元数据缺失、图像评估证据、停止等待、消息身份与跨画布隔离。未使用真实付费服务或 Windows 实机、浏览器进行端到端验收。
