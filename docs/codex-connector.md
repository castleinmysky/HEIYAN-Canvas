# 连接你自己的 Codex（源码包）

普通 Windows x64 用户请优先使用画布连接面板中的“下载 Windows 免安装包”：完整解压后双击“启动黑岩连接器.cmd”，按本机页面引导登录和配对，无需安装 Node.js。此文档对应“其他系统 / 手动启动”中的源码包。

先在本机安装 Node.js 22 或更高版本，以及 Codex CLI，并自行登录 Codex。画布不提供账号、不复制登录凭据、不代售模型额度。

1. 解压连接器压缩包，在解压目录打开终端。
2. 在画布中打开 Agent → Codex 未连接，复制该页面显示的启动命令并运行，例如：

   `npm run agent:connector -- --origin https://heiyan.f2vfhjcckr.chatgpt.site`

   本地正式画布使用 `--origin http://127.0.0.1:8792`。协议、主机和端口必须与浏览器地址一致。
3. 将终端显示的连接地址、十分钟有效的配对码填入画布，点击“配对并连接”。在线页面可能要求允许本地网络访问。
4. 连接成功后才发送消息。消息使用你自己的 Codex 额度；修改节点需按当前审批模式执行，真实媒体生成永远需要在画布明确确认。

连接器仅监听本机回环地址，只允许一个指定网页来源和明确配对的浏览器。关闭终端会断开会话，但不会关闭其他 Codex 任务。新连接不会自动提交消息。

目前支持会话、读取带端口与连线类型的当前画布节点元数据，确认后创建、编辑和自动匹配合法端口连接节点，以及一次请求最多 4 个已存在的生成节点。Windows 1.3.0 连接器会返回当前账号实际可用的模型、思考程度与视觉输入能力；会话框可直接粘贴最多 4 张 PNG/JPEG/WebP 图片。明确附加的图片会发送给用户自己的 Codex/OpenAI 进行分析，但 Agent 不会自行读取画布素材原图。真实生成会单独显示模型与资源消耗提醒，不会被“帮我批准”自动通过。Agent 不听音频，也不会自动剪辑或生成完整短片。

手机连接另一台电脑的 Codex、跨机远程配对、关闭连接器后的持久会话恢复尚未开放。在线 Site 配对的也是浏览器所在电脑的 Codex，不是网站作者的机器。

若系统找不到 codex，可在本机进程环境中设置 HEIYAN_CODEX_BIN 为自己的 Codex 可执行文件路径；不要向网页或他人发送密码、登录文件和 API 密钥。
