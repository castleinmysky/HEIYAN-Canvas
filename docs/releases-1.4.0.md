# HEIYAN Canvas 1.4.0

这一版把 Agent 从传统侧栏入口升级为画布中的常驻 Living Bot，同时保留 1.3.0 的连接器、权限和画布能力契约。

## Living Bot

- 空闲时以 64px 矢量 Bot 常驻画布底部；首次点击打开快速输入，不制造空白完整会话。
- 根据真实运行状态呈现读取、思考、执行、等待结果、审核、提问、授权、完成、异常和休眠动作。
- 紧凑态显示最近一条真实 Agent 回执，按内容需要分档变宽；执行中提供补充要求和停止入口。
- 展开态保留会话历史、模型与思考等级、审批模式、节点引用、图片粘贴和未来连续语音入口。

## 画布协作

- Bot 可在中下方自由拖动，靠近边缘时无提示磁吸到左右工作栏；展开时选择最近工作位，收起后回到此前自由位置。
- Bot 会观察当前选中或正在处理的节点，节点使用轻量轮廓回应，不拦截画布操作。
- 图片/视频节点编辑窗会避让浮动 Bot；底部键盘快捷入口也不会与 Bot 叠放。
- 点击画布空白处可快速折叠完整会话，但文字选择、输入法组合和控件操作不会误触发。

## 视觉与可访问性

- Bot 使用无损 SVG，不会因放大变糊；Motion 负责弹性形变和表面 FLIP 过渡。
- 白昼与黑夜共享同一套圆润、低噪声令牌，并保留明显的键盘焦点。
- 系统开启减少动态效果时，会自动关闭非必要的形变与流光。

## 边界

- 本次没有更换连接器协议或 Windows 安装包，现有 1.7.0 开源连接器继续兼容。
- 麦克风入口明确标记为尚未接通，不会录音；连续语音需要后续单独接入。
