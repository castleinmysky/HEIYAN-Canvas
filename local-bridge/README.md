# ComfyUI 连接器

[返回首页](../README.md) · [快速开始](../docs/QUICKSTART.md)

连接自己的 ComfyUI，模型和生成仍在部署机器运行。本目录包含网关、已有工作流适配和引擎源码，不包含 ComfyUI 程序、Python、模型或 LoRA。

## 当前电脑

先启动 ComfyUI。在已经执行 `npm ci` 的仓库根目录运行：

```bash
npm run comfy:connector -- --origin http://127.0.0.1:8792 --comfy-port 8188
```

打开 [配对信息](http://127.0.0.1:8289/)，在画布「设置 → 远程 ComfyUI 生成 → 当前电脑」填写连接地址与配对码。浏览器询问本地网络权限时，只允许自己信任的连接器。

| 参数 | 用途 |
| --- | --- |
| --origin | 实际画布来源，不含路径；默认 http://127.0.0.1:8792。只允许这个来源。 |
| --comfy-port | 已启动的本机 ComfyUI 端口，默认 8188。 |
| --port | 本机连接器端口，默认 8289。 |
| --comfy-dir | 可选的 ComfyUI 目录；用于补充本机模型目录信息，路径有空格时加引号。 |
| --state-dir | 状态与结果副本目录，默认仓库 .runtime/comfy。 |
| --remote | 明确开启下面的临时 HTTPS 通道；默认不开启。 |

连接只做发现和校验，不自动生成，不安装或搬动模型。模型列表取决于节点、权重和已有适配器；任意自定义工作流不保证自动适配。API 入口不暴露完整 ComfyUI 编辑器、终端或任意文件操作。

## 跨网络访问

Windows x64 可使用可选的 Cloudflare 临时通道。先明确接受：提示词、素材和生成结果会经过 Cloudflare，地址在重新启动后可能变化。生成机器必须保持运行。

只在需要此能力时运行：

```bash
node local-bridge/install-tunnel.mjs
npm run comfy:connector -- --origin https://canvas.example.com --comfy-port 8188 --remote
```

将示例来源换为自己实际访问的 HTTPS 画布来源。下载脚本获取固定版本的官方 cloudflared，验证大小和 SHA-256，保存许可证，不会自动启动通道。第二条命令才会开启通道。

打开本机配对页获取 HTTPS 地址和独立远程访问码，在另一台设备的画布中选择「其他网络的机器」。不要把本机配对页或其访问码分享出去。

通道仅转发受限网关，内部引擎和配对页不会被转发。HTTPS 地址不是身份验证，仍必须保密并使用独立访问码。停止连接器后通道关闭。

当前自动下载脚本仅适用于 Windows x64，其他系统可自行配置受保护的 HTTPS 反向代理到受限网关；不应直接暴露 ComfyUI 或内部引擎。其他系统的远程部署需自行验收。

## 结果和任务

原始结果仍在 ComfyUI 输出目录；连接器保存返图副本，默认位于 `.runtime/comfy/data/outputs`。浏览器保存画布和历史所需数据。清浏览器生成历史，不会删除部署机器原图。

刷新网页不等于取消已提交的本地任务。需要保持 ComfyUI 和连接器运行；断电、关闭连接器或清除状态后不承诺恢复，也不会自动重复提交不确定的任务。

## 兼容已有部署包

`entry.mjs`、`build-addon.mjs` 和同目录的 CMD 脚本保留旧完整部署包补充安装方式，要求既有 HEIYAN/ComfyUI 目录结构；它们不是新用户默认启动入口。一般源码部署使用上面的 `npm run comfy:connector`。

`engine/` 是本连接器使用的服务、适配器和工作流源码。内部兼容字段可能保留旧前缀，不需要作者的账号或固定磁盘路径。不要把 engine 当作对公网的通用服务单独运行。
